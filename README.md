# CA2: Process Creation vs Thread Creation

A beginner-friendly Python benchmark for comparing process and thread creation
overhead and observing how the two models behave for CPU-bound and I/O-bound work.

## What this project measures

1. **Creation + join time:** starts and joins one no-op thread or process several times.
2. **CPU workload:** runs a fixed Python calculation using a thread pool and process pool.
3. **I/O workload:** runs short blocking waits using a thread pool and process pool.
4. **Worker scaling:** repeats workloads with 1, 2 and 4 workers by default.

The program writes measurements from the computer where it is run to
`results/benchmark_results.csv`. The numbers will vary by computer, operating
system, Python version, background activity and run settings.

## Requirements

- Python 3.9 or newer
- No third-party Python packages required

## Run it

Open a terminal in the project folder:

```bash
python --version
python src/benchmark.py
```

On some systems, use `python3` instead of `python`:

```bash
python3 src/benchmark.py
```

Optional: increase repetitions and worker counts:

```bash
python src/benchmark.py --repeats 5 --workers 1 2 4 8
```

The process benchmark uses Python's `spawn` start method so it can run on
Windows, macOS and Linux. Process startup includes interpreter startup overhead;
it is not a measurement of raw kernel `fork()` latency.

## Important notes

- Run the benchmark at least twice and keep the CSV generated by your own run.
- Do not copy example numbers from another machine and describe them as yours.
- This is a compact starter experiment, not a complete reproduction of every
  parameter in the written report or every possible CA2 requirement.
- The report's Rust, parent-memory sweep, PSS memory, and IPC experiments are
  not implemented in this starter version. Add them only if your instructor's
  rubric requires them and your environment supports them.
